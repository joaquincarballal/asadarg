# Standing rules (read every session — no exceptions)

## No unsupervised action
- Never write/edit code, run migrations, git commit/push, or deploy without explicit go-ahead for THAT action ("dale", "avanza", "confirmo").
- Confirming a design/plan is NOT confirming implementation. Ask again before writing code.
- Applies for the whole session, not just the first few replies.

## Response style
- Terse. Caveman bullet points. No prose paragraphs, no preamble, no restating the question.
- Code/diffs shown as needed; everything else is bullets.
